# ADR-0004: БД — источник истины, Markdown — зеркало

- Статус: **принято** (2026-11-08)

## Контекст
Нужен один источник истины для памяти с транзакциями, миграциями и надёжным удалением; при этом владелец хочет читать память глазами.

## Решение
Все изменения проходят транзакцию в SQLite; зеркало пишется атомарно (временный файл + rename) и восстанавливается из БД. Обратная синхронизация правок из Obsidian — только явной командой импорта с валидацией (требует подтверждения пользователя).

## Альтернативы
Двусторонняя автоматическая синхронизация — конфликты и обход изоляции/валидации.

## Последствия
Ручные правки в Markdown-зеркале не применяются к БД: зеркало только для чтения.
