# ADR-0004: БД — источник истины, Markdown — зеркало

- Статус: предложено (Phase 0, 2026-11-08)

## Контекст
В alya-v2 источник истины — Markdown (Obsidian), SQLite — перестраиваемый индекс; в Kuni — Markdown-файлы с JSON-метаданными. Спецификация: БД — источник истины, файлы — атомарное зеркало с YAML frontmatter.

## Решение
Все изменения проходят транзакцию в SQLite; зеркало пишется атомарно (временный файл + rename) и восстанавливается из БД. Обратная синхронизация правок из Obsidian — только явной командой импорта с валидацией (требует подтверждения пользователя).

## Альтернативы
Двусторонняя автоматическая синхронизация — конфликты и обход изоляции/валидации.

## Последствия
Ручные правки в Obsidian больше не применяются мгновенно, как в v2 — это изменение поведения, вопрос вынесен пользователю.
