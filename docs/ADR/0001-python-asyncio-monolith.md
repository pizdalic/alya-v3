# ADR-0001: Python 3.12+, модульный монолит на asyncio

- Статус: **принято** (2026-11-08)

## Контекст
Проект пишется с нуля. Нужны быстрые итерации, готовые библиотеки (TDLib-обёртки, SDK LLM, NumPy) и простой деплой на один сервер.

## Решение
Python 3.12+, один процесс на asyncio, модули с явными зависимостями через DI и Event Bus.

## Альтернативы
Микросервисы — лишняя сложность для одного персонажа. Компилируемые языки — медленнее разработка, меньше готовых SDK.

## Последствия
Производительность для одного персонажа не критична; тяжёлые вычисления (векторы) — NumPy.
