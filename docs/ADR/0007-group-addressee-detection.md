# ADR-0007: Определение адресата сообщений в группах

- Статус: **принято** (2026-11-08, решение владельца)

## Контекст
Владелец хочет, чтобы Аля понимала обращения без reply: если она спросила «а ты как?», а человек просто написал ответ, это сообщение ей.

## Решение
Компонент Addressee Detector (ARCHITECTURE.md §4.1): явные сигналы и анти-сигналы → активные нити разговора с TTL → score по признакам → в серой зоне дешёвый LLM-классификатор адресата. При сомнении — молчать.

## Альтернативы
- Только mention/reply — неестественно, Аля «не слышит» ответы.
- LLM-классификатор на каждое сообщение группы — дорого и медленно.
- Только эвристики — ошибается в оживлённых чатах.

## Последствия
- Дополнительные LLM-вызовы в серой зоне (бюджет).
- Нити разговора хранятся в памяти процесса (решение Phase 4): они живут минуты, таблица не нужна. Сценарные тесты — tests/test_addressee.py и tests/test_pipeline.py.
- Аля видит чужие сообщения группы для классификации; что из них сохранять в память — решение владельца (политика хранения).
