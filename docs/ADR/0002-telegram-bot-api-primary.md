# ADR-0002: Bot API — основной транспорт, TDLib — опциональный адаптер

- Статус: предложено (Phase 0, 2026-11-08)

## Контекст
Kuni и alya-v2 работают как userbot через TDLib (Kuni собирает TDLib из исходников). README Kuni сам указывает на нарушение ToS. Спецификация: Bot API через aiogram 3.x, TDLib опционально, без сборки в Docker.

## Решение
Основной адаптер — aiogram 3.x. TDLib-адаптер реализуется только после отдельного решения пользователя и использует prebuilt libtdjson (кандидаты: python-telegram 2.0.0, tdjson 1.8.69).

## Альтернативы
Только TDLib (как v2) — риск блокировки аккаунта, тяжёлая сборка. Только Bot API — теряются функции пользовательского аккаунта (вступление в чаты по ссылке, set_bio, Secret Chats недоступны и так).

## Последствия
Часть возможностей alya-v2 (вход в чаты по инвайту, смена bio, личный аккаунт @AlysiaNya) в режиме бота недоступна — это нужно подтвердить с пользователем.
