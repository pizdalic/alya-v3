# ADR-0006: Код Kuni не переиспользуется

- Статус: предложено (Phase 0, 2026-11-08)

## Контекст
В репозитории alex2772/kuni (коммит 3bbf87d6) нет файла LICENSE в корне, поиск по коду лицензии не нашёл. Без лицензии код по умолчанию защищён авторским правом. Кроме того, это C++.

## Решение
Из Kuni берутся только идеи и архитектурные приёмы с указанием источника в документации; код, промпты и тексты не копируются.

## Альтернативы
Запросить у автора лицензию — возможно, но не блокирует проект.

## Последствия
Если автор добавит лицензию, решение можно пересмотреть.
