# ADR-0008: Проактивность (личка и группы)

- Статус: **принято** (2026-11-08, решение владельца)

## Контекст
Владелец хочет, чтобы Аля иногда писала первой как живой человек: по контексту, когда «скучно» или есть что сказать, но не часто. В группах она иногда вступает в разговор сама.

## Решение
**Желание написать** — числовой score, который пересчитывается планировщиком (не на каждое сообщение):
- время с последнего контакта с человеком;
- эмоциональное состояние (низкий arousal ≈ скука; сильная эмоция ≈ хочется поделиться);
- незакрытые поводы: обещания, напоминания, «хотела рассказать», вопрос без ответа;
- отношение к человеку (affinity, trust);
- случайность в небольших пределах.

Если score выше порога, дешёвая модель решает «есть ли что сказать» и предлагает повод; затем обычная двухэтапная генерация.

**Жёсткие ограничения в личке** (конфигурируемые, значения стартовые):
- тихие часы 23:00–09:00 по Екатеринбургу;
- не больше 1 инициативного сообщения в сутки на человека;
- не писать повторно, если прошлое инициативное сообщение осталось без ответа;
- только людям с устоявшимся диалогом; `/pause` отключает.

**В группах:** вступает сама только в активном обсуждении темы из её интересов (сначала дешёвая проверка совпадения с интересами, затем модель), не чаще одного раза за несколько часов на чат, не встревает в явно личный разговор двоих.

## Альтернативы
- Таймер «раз в N часов» — механично.
- Модель решает на каждом тике по всем чатам — дорого.

## Последствия
Нужны таблица причин («поводов»), метрики инициатив и сценарные тесты с фиктивным временем.
