# ADR-0001: Новая реализация на Python 3.12+, а не порт C++

- Статус: предложено (Phase 0, 2026-11-08)

## Контекст
Kuni и alya-v2 написаны на C++20 (CMake; Kuni — с AUI и корутинами). Спецификация v3 требует Python 3.12+.

## Решение
Пишем v3 с нуля на Python. Из предшественников переносятся идеи, контент персонажа и тестовые сценарии, но не код.

## Альтернативы
1) Продолжать alya-v2 на C++ — противоречит ТЗ. 2) Python-обвязка вокруг C++ ядра — две сборки, сложный деплой.

## Последствия
Нет прямого переиспользования кода; выигрываем в экосистеме (aiogram, SDK провайдеров, NumPy). Производительность для одного персонажа не критична.
