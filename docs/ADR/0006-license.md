# ADR-0006: Лицензия PolyForm Noncommercial 1.0.0

- Статус: **принято** (2026-11-08, решение владельца)

## Контекст
Владелец хочет, чтобы код можно было копировать и изменять, но нельзя было продавать.

## Решение
PolyForm Noncommercial License 1.0.0 с Required Notice «Copyright (c) 2026 pizdalic». Лицензия разрешает использование, копирование, изменение и распространение в некоммерческих целях и запрещает коммерческое использование, включая продажу.

## Альтернативы
- CC BY-NC-SA 4.0 — Creative Commons не рекомендует свои лицензии для ПО.
- MIT / Apache-2.0 — разрешают продажу.
- Без лицензии — копировать и изменять никому нельзя.

## Последствия
- Проект не является open source по определению OSI (это source-available).
- Зависимости должны быть совместимы: MIT / Apache-2.0 / BSD подходят. Лицензии Pytdbot, tdjson и TDLib (по сведениям — BSL-1.0, не проверено) проверяются в Phase 1.
- Это не юридическая консультация; для коммерческих сценариев нужен юрист.
