# ADR-0005: Эмоции как VAD-вектор с decay и дневником

- Статус: предложено (Phase 0, 2026-11-08)

## Контекст
alya-v2 хранит эмоции текстом в Emotions.md; Kuni — без явной численной модели. Спецификация требует valence/arousal/dominance, decay и emotional diary.

## Решение
Состояние в [-1, 1] по трём осям на scope (пользователь+чат), экспоненциальное возвращение к базовой линии персонажа с настраиваемым периодом полураспада; дельты ограничены по величине за одно событие; каждая дельта пишется в diary с причиной. Метка эмоции выводится из вектора, а не наоборот.

## Альтернативы
Дискретные эмоции без чисел — нельзя сделать плавный decay. Одно глобальное настроение — ссора в одном чате «заражает» другие.

## Последствия
Нужно калибровать коэффициенты; планировщик получает компактную текстовую сводку состояния.
