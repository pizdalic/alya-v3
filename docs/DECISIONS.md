# Решения владельца

Сводка ответов на вопросы Phase 0 (2026-11-08). Пункты с пометкой «решение архитектора» владелец оставил на моё усмотрение.

| # | Тема | Решение |
|---|---|---|
| 1 | Репозиторий | публичный (переключается владельцем вручную) |
| 2 | Лицензия | PolyForm Noncommercial 1.0.0 — ADR-0007 |
| 3 | Транспорт | userbot на @AlysiaNya; api_id/api_hash есть, 2FA включена — ADR-0002 |
| 4 | Группы: адресат | понимает ответы себе без reply — ADR-0008 |
| 5 | Группы: инициатива | иногда вступает сама — ADR-0009 |
| 6 | Группы: память | чужие сообщения хранятся только 1–3 дня как контекст чата, долговременные факты из них не извлекаются |
| 7 | Модели | всё через API; основной провайдер — OpenRouter; base_url и модель владелец задаёт сам в конфиге — ADR-0010 |
| 8 | Эмбеддинги | через тот же API (у OpenRouter есть /embeddings); модель задаётся в конфиге |
| 9 | Бюджет | ключ и баланс уже есть; жёсткого лимита по умолчанию нет, но есть настраиваемые лимиты и метрики расхода |
| 10 | Сервер | Ubuntu последней версии, архитектура CPU неизвестна → образ под amd64 и arm64, setup проверяет `uname -m` |
| 11 | Функции userbot | вступление по ссылке, bio и аватар, реакции, голосовые (STT и TTS), чтение каналов, стикеры, веб-поиск и остальные возможности Kuni — см. ARCHITECTURE §11 |
| 12 | Obsidian | **решение архитектора:** зеркало только для чтения, включено по умолчанию; правки персонажа — через файлы `character/` в git |
| 13 | Память v2 | не переносится, чистый старт |
| 14 | Характер | переносится из alya-v2/character и редактируется вместе с владельцем (первый шаг Phase 3) |
| 15 | Граница дня | Asia/Yekaterinburg (UTC+5) |
| 16 | Проактивность в личке | иногда, по контексту или «когда скучно/есть что сказать», редко — ADR-0009 |
| 17 | Язык | только русский |
| 18 | Бэкапы и /forget | **решение архитектора** — ADR-0011 |
