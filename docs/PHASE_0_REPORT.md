## 3. Что переписать и почему

- **Весь код** — C++ → Python (ADR-0001); код Kuni без лицензии (ADR-0006).
- **Поиск alya-v2:** при каждом запросе индекс FTS5 очищается и заполняется заново из файлов — не масштабируется; заменяется транзакционным индексом.
- **JSON в alya-v2 model.cpp** разбирается вручную (\u-последовательности заменяются на «?») — в v3 только нормальный JSON-парсер и SDK.
- **digest через std::hash** — нестабилен между сборками; в v3 — ULID/хеш SHA-256.
- **Markdown как источник истины** → БД как источник истины (ADR-0004).
- **Автономная модерация с банами** (alya-v2 full_control_chats) — не переносится: спецификация требует dry_run.
- **Userbot** (Kuni, alya-v2) → Bot API (ADR-0002).
- **Отсутствие изоляции в Kuni** — исправляется архитектурно.

## 4. Предлагаемая архитектура

Модульный монолит на asyncio: Event Bus + DI, per-chat очереди, SQLite WAL как единое хранилище, гибридный поиск FTS5 + NumPy + RRF, двухэтапная генерация, outbox для отправки, все внешние провайдеры за интерфейсами с capabilities. Подробно — docs/ARCHITECTURE.md.

## 5. Подтверждённые версии

aiogram 3.31.0 (MIT, Python 3.10+, Bot API 10.3); sqlite-vec 0.1.9 (Apache-2.0, < 1.0); python-telegram 2.0.0 (prebuilt TDLib в wheel, Python 3.10–3.14, без Windows); tdjson 1.8.69 (prebuilt-бинарники). Остальные зависимости **не проверены** — список в docs/DEPENDENCIES.md.

## 6. Риски и ограничения

- **R-1** Bot API не умеет того, что умел userbot v2 (вход по инвайтам, bio, личный аккаунт).
- **R-2** Качество персонажа зависит от выбранной модели; без доступа к модели нельзя проверить характер.
- **R-3** Эмбеддинг-провайдер не выбран; без него — только FTS5.
- **R-4** Наличие FTS5 в SQLite образа не проверено.
- **R-5** sqlite-vec < 1.0 — только опционально.
- **R-6** Лицензия Kuni неизвестна — только идеи.
- **R-7** Стоимость: двухэтапная генерация удваивает число вызовов LLM — нужен бюджет и, возможно, дешёвая модель для этапа плана.
- **R-8** Калибровка VAD и порогов Dream Engine — эмпирическая.
- **R-9** **Среда выполнения тестов:** у меня есть GitHub MCP и песочница, но в песочнице по умолчанию нет интернета — установка pip-пакетов может не сработать. Тогда тесты будут запускаться в GitHub Actions; результаты я буду брать оттуда, а не заявлять без проверки.
- **R-10** Проактивность и эмоции в группах — социальные риски; по умолчанию выключено.
