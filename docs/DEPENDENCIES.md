# Зависимости

Дата проверки: 2026-11-08. Источник — страницы PyPI / GitHub, найденные веб-поиском. «Не проверено» значит, что в Phase 0 версия и совместимость **не подтверждены** и должны быть проверены в начале Phase 1. Фиксация версий (lock-файл) — в Phase 1.

## Целевая платформа

- Python **3.12** (минимум по спецификации), CI-матрица 3.12 и 3.13.
- `tomllib` — стандартная библиотека (Python ≥ 3.11), отдельная зависимость не нужна.
- `sqlite3` — стандартная библиотека; **наличие FTS5 зависит от сборки SQLite** в образе — проверить в Phase 1 тестом при старте.

## Принципы выбора

- Предпочтение пакетам с готовыми wheel для Linux x86_64 / aarch64 — без компиляции в Docker.
- Тяжёлые и необязательные (TDLib, FAISS, sqlite-vec, STT/TTS) — extras в pyproject, по умолчанию не устанавливаются.
- Каждая опциональная зависимость обязана иметь работающий путь без неё.
