# Зависимости

Актуально на 2026-11-09. Источник истины — `pyproject.toml`; этот файл описывает, что и зачем ставится.

## Платформа

- Python **3.12+**, CI-матрица 3.12 и 3.13.
- Хост: Ubuntu + Docker, образ собирается под `linux/amd64` и `linux/arm64`.
- Все модели (LLM, эмбеддинги, vision, STT, TTS, картинки) — через облачные API (OpenRouter); локальных моделей нет.
- `tomllib`, `sqlite3` — стандартная библиотека. Нужна сборка SQLite с **FTS5** (проверяется при старте).
- **ffmpeg** — системный пакет, ставится в Docker-образе. Без него голос отключается с предупреждением, остальное работает.

## Python-пакеты

| Группа | Пакет | Ограничение версии | Лицензия | Роль |
|---|---|---|---|---|
| базовые | pydantic | `>=2.7,<3` | MIT | конфиг и модели данных |
| базовые | numpy | `>=1.26` | BSD-3-Clause | косинусный поиск по эмбеддингам (fallback без sqlite-vec) |
| `[tg]` | tdjson | `>=1.8.69,<1.9` | BSL-1.0 (TDLib) | prebuilt libtdjson для userbot-режима |
| `[vec]` | sqlite-vec | `>=0.1.9` | Apache-2.0 / MIT | опциональный ускоритель векторного поиска (API < 1.0 может меняться) |
| `[dev]` | pytest | `>=8` | MIT | тесты |
| `[dev]` | ruff | `>=0.6` | MIT | линтер |
| `[dev]` | mypy | `>=1.11` | MIT | статическая типизация (strict) |

Клиент TDLib и адаптер Bot API — собственные тонкие обёртки (ADR-0002), отдельные SDK не нужны.

## Варианты установки

| Сценарий | Команда | Что работает |
|---|---|---|
| Минимальная | `pip install .` | CLI, конфиг, миграции, память, `alya chat`, режим `telegram.mode=bot` |
| Userbot | `pip install ".[tg]"` | + основной режим через TDLib |
| Полная | `pip install ".[tg,vec]"` | + ускоренный векторный поиск |
| Разработка | `pip install -e ".[dev]"` | + ruff, mypy, pytest (как в CI) |
| Docker | `docker compose build` | всё вышеперечисленное + ffmpeg |

Каждая опциональная зависимость имеет рабочий путь без неё.

## Рассматривались, но не используются

| Пакет | Почему нет |
|---|---|
| aiogram | Bot API-адаптер свой, лишняя зависимость |
| Pytdbot, python-telegram, aiotdlib | выбран свой тонкий клиент TDLib (ADR-0002) |
| aiosqlite | sqlite3 в отдельном потоке |
| httpx, официальные SDK провайдеров | прямые HTTP-вызовы к OpenRouter |
| structlog, prometheus-client | logging + JSON formatter |
| faiss-cpu | sqlite-vec / NumPy достаточно |

## Принципы выбора

- Пакеты с готовыми wheel для Linux x86_64 / aarch64 — без компиляции в Docker.
- Тяжёлые и необязательные зависимости — только в extras.
- Каждая опциональная зависимость обязана иметь работающий путь без неё.
